# Agent handbook

Read README.md and docs/ARCHITECTURE.md before changes. Single administrator, no registration. Mandatory TOTP and strong administrator passwords; restricted enrollment/recovery sessions must never read mail or send messages. Keep anti-replay checks atomic and recovery codes single-use. Credentials, TOTP seeds, authenticated proxy URLs and custom notification headers are encrypted with the volume master key, never returned in normal state APIs or logged. Enrollment QR/setup key and fresh recovery codes may only be returned in their authenticated setup flow; never capture them in tools or screenshots. Preserve provider identities, IMAP UIDVALIDITY/UID and Graph delta checkpoints. Bootstrap history must not notify. Reading must not mutate upstream read/delete flags. Plaintext mail supports recognized safe links, no HTML execution or remote images. Only explicit authenticated sends can call SMTP/Graph; never send real mail during tests. Keep submission IDs idempotent and do not automatically retry uncertain delivery. Optional account proxies apply to IMAP, SMTP and account OAuth/Graph only. Blacklists override allow rules per channel. Custom webhook JSON must be parsed before variable replacement; reject connection/header injection. Keep language/theme preferences device-local and preserve message text. Schema v2 migrates v1 without resetting credentials or mail; new encrypted backups must be rejected by old builds. Network operations have deadlines and bounded sizes. Persist notification dedupe and retry progress. Validate backup before transactional restore; restore invalidates sessions. Never ship sample emails as production data. Keep real test data outside this repository. Build frontend before Go embed; run meaningful backend, frontend, race and browser tests. Public release requires explicit request and tested version tags.
