# Agent handbook

Read README.md and docs/ARCHITECTURE.md before changes. Single administrator, no registration. Credentials are encrypted with the volume master key, never returned by APIs or logged. Preserve provider identities, IMAP UIDVALIDITY/UID and Graph delta checkpoints. Bootstrap history must not notify. Reading must not mutate upstream read/delete flags. Browser renders plain text only in v0.1, no remote message HTML/assets. Network operations must have deadlines and bounded sizes. Persist notification dedupe and retry progress. Validate backup before transactional restore; restore invalidates sessions. Never ship sample emails as production data. Keep real test data outside this repository. Build frontend before Go embed; run meaningful backend and browser tests. Public release requires explicit request and tested version tags.
