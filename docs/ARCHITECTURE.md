# Architecture

Go embeds Vue, SQLite persists an atomic bounded state snapshot. Per-account adapter: IMAP TLS + authorization/app password for QQ,163,Gmail; Microsoft Graph delegated OAuth device authorization for Outlook. Server owns synchronization and notification queues. Mail headers cached; body/attachments fetched on demand with size caps. AES-256-GCM for credentials; private volume key. Portable password-encrypted backup includes decrypted logical secrets inside the encrypted archive, never as a loose file. No third-party cloud hosting or analytics. Single administrator, no public registration. Public HTML mail content is never executed. Source and Docker preview use independent data directories.

v0.2: schema version2, with atomic v1 migration and backward backup import. Authenticated enrollment sessions are restricted until a strong password and TOTP enrollment are complete. Session epochs revoke old logins after credential changes/restores. TOTP/recovery consumption is persisted atomically. Per-account encrypted HTTP CONNECT/HTTPS/SOCKS5 proxy configuration feeds mail/OAuth adapters without affecting notification transports. Outbound messages use fixed provider SMTP TLS endpoints or Graph Mail.Send; a durable submission ID prevents duplicate clicks/retries. Body and attachments are not persisted in outgoing history. Webhook transport configuration is separate from per-rule content and allow/block policy. Request headers remain encrypted; JSON template replacement walks parsed values so mail text cannot escape JSON strings. Vue text nodes plus validated link parts preserve message text without executing HTML. Desktop/tablet/mobile share one translated component set; only language and theme preferences are stored by the browser.
